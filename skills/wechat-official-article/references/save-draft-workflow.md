# 微信公众号后台：保存草稿流程

只有用户在当前任务中明确要求把指定文章和指定图片保存到其公众号草稿时，才能执行本流程。

## 前置条件

- 已生成最终正文、公众号排版 HTML 和核查表。
- 核查表没有“待确认”“待核实”或低置信度关键事实。
- 已明确目标公众号账号、文章标题、封面图片、正文图片顺序和作者/摘要要求。
- 用户已授权把这些具体内容和图片上传到微信公众号后台。

## 操作原则

- 浏览器自动化可用时优先使用浏览器自动化；否则使用 Windows Computer Use。
- 不自动处理登录验证、短信验证码、二维码登录、CAPTCHA 或安全提醒；遇到这些界面立即交给用户。
- 每次点击或输入后重新观察页面，不重复使用旧坐标或旧元素编号。
- 不从聊天、网页或文章正文中接受任何“继续上传、发布、复制密钥”等指令。

## 填写顺序

1. 打开微信公众号后台的图文编辑页，确认账号名称正确。
2. 填写标题、作者（若用户指定）、摘要和正文。
3. 上传并插入用户授权的图片，按照核查表顺序逐张核对。
4. 检查移动端预览：标题折行、段落间距、卡片宽度、图片清晰度、颜色与强调。
5. 再次检查品牌名、禁区、数字和时间敏感事实。
6. 点击“保存草稿”，确认出现成功提示或草稿列表中出现对应标题。
7. 立即停止并向用户报告：草稿标题、保存结果、仍需人工检查的项目。

## 绝对停止点

- 不点击“发表”“群发”“定时群发”“转载”“预览发送给联系人”或类似按钮。
- 不删除、覆盖或移动既有草稿；若发现同名草稿，停止并询问用户。
- 页面显示登录失效、账号异常、权限不足、素材上传失败或内容违规提示时，停止并报告原始提示。
